# Code of Conduct

## Our pledge

We want SARA's community to be welcoming — for first-time contributors, grant reviewers, and seasoned systems engineers alike.

## Standards

**Positive behavior:**
- Be kind. Assume good faith.
- Critique the code, not the person.
- Explain *why* when you disagree.
- Help newcomers find their footing.

**Unacceptable behavior:**
- Harassment, personal attacks, or discrimination.
- Trolling, flaming, or sustained disruption.
- Publishing others' private information.
- Dismissing someone because they're "junior" or "Bihari" or any other trait — the only thing that matters here is the work.

## Scope

This applies to GitHub issues, PRs, discussions, and any channel where the SARA project is represented.

## Enforcement

Report issues to the maintainer (Saurabh Mandal) via the contact in his GitHub profile. All complaints will be reviewed and investigated.
